#  Sahajanand Jewellers

> **Most Trusted Brand Since 1992**

A modern, responsive jewellery website designed for **Sahajanand Jewellers**, showcasing their jewellery collections, signature creations, and brand identity through a clean and elegant user interface.

## 🌐 Live Project

👉 **[Visit Sahajanand Jewellers](https://jaypanchal-sde.github.io/sahajanad-jewelers/)**

## 📸 About the Project

Sahajanand Jewellers is a frontend web project created to provide a premium digital presence for a jewellery brand.

The website allows visitors to:

* Explore jewellery categories
* Browse exclusive collections
* Discover signature jewellery creations
* Learn about the brand
* Find contact information
* Navigate through a responsive and visually-focused interface

## ✨ Features

* 🏠 **Modern Landing Page**
* 💍 **Jewellery Categories**

  * Necklaces & Pendants
  * Bracelets
  * Earrings

* ✨ **Signature Collections**

  * Viraasat

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/jaypanchal-sde/sahajanad-jewelers.git
```

### 2. Navigate to the project

```bash
cd sahajanad-jewelers
```

### 3. Open the project

You can simply open `index.html` in your browser.

Alternatively, use **VS Code Live Server** for local development.
